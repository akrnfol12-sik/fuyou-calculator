# 扶養計算機

Googleカレンダーの予定名から、ビックカメラのバイト代とエンダストリアルのインターン代を集計し、扶養ラインを確認するブラウザアプリです。

## 予定名ルール

Googleカレンダー側では、次のように入れる想定です。

- `バイト｜ビックカメラ`
- `インターン｜エンダストリアル`

アプリ内では表記ゆれも登録できます。

- ビックカメラ: `バイト｜ビックカメラ`, `びっくかめら`, `ビック`, `bic`
- エンダストリアル: `インターン｜エンダストリアル`, `インターン`, `エンダ`, `endustrial`

## 計算ルール

- ビックカメラ: 時給 1,150 円
- ビックカメラ加算: 平日 17:00-21:00 は +100 円 / 時
- ビックカメラ加算: 土日祝 10:00-21:00 は +200 円 / 時
- エンダストリアル: 時給 1,230 円
- 6 時間超は 45 分、8 時間超は 60 分の休憩を自動入力
- 健保判定では交通費を収入に含められるようにしています

## 扶養ライン

- すかいらーく健保の通常目安: 130 万円未満
- 19 歳以上 23 歳未満の目安: 150 万円未満
- 税扶養の目安: 123 万円
- 特定親族の満額目安: 150 万円
- 本人の所得税目安: 160 万円

## 開発

```bash
pnpm install
pnpm dev
pnpm run build
```

ローカル起動後、ブラウザで `http://localhost:3000/` を開きます。
